# Contributing

Open a focused issue or pull request with a reproducible example using dummy data. Run `npm ci`, `npm run check`, and `npm test`. Add regression tests when changing filesystem behavior, model-response validation, or provider requests.

Do not add automatic shell execution or bulk repository upload to a small fix. Preserve explicit file selection, review before write, no credential logging, and conflict-aware recovery. Use exact installed SDK docs when changing integrations. Keep live API calls out of CI.
